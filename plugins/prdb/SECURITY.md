# Reporting a private problem

Report suspected account isolation problems or sensitive failures through [PRDB Support](https://prdb.ai/support) or issues@prdb.ai. Include a minimal reproduction and redacted error. Do not publish another person's data, secrets, private PDFs or notes in GitHub issues.

Ordinary reading uses your own PRDB account and browser OAuth. You choose operations and may revoke the connection in My Account → Connections. The plugin contains no account credentials, administrator connection, installation hooks or local server runtime. Its optional picker runs only when requested, uses the human's file selection and waits for browser confirmation.

The public trial is maintained by PRDB. It has not been approved for the OpenAI directory; supported clients and known limitations are in the README. This notice does not promise a security response time or replace the service's privacy/terms disclosures.
