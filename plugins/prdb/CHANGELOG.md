# PRDB plugin releases

## 0.1.0 · 2026-10-13 · public trial

- Stable plugin identity `prdb`, display name **PRDB**, production reading MCP and shared paper icon.
- Standalone installation/onboarding/feedback guide and pinned public GitHub marketplace.
- Existing OAuth reading, private upload, exact highlights/comments, private review, owner-confirmed publication and selected export workflows use the existing PRDB production service.
- A one-PDF browser import is the runtime-free starting path; the OS picker remains optional.

The plugin version is independent of the website release. Earlier `prdb-reading-preview` installations are not replaced automatically. Fresh-machine human installation/upload testing and generic direct chat attachment transport are separate. This version has not been submitted to the OpenAI public directory.
