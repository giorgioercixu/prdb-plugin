# PRDB plugin releases

## 0.2.0 · 2026-10-13 · public trial

- Three skills: setup, reading and ordinary daily actions. Optional operation permissions are selected in browser OAuth; old grants stay unchanged.
- Installation diagnostics, browser registration/verification handoff and actual connection-owner identification.
- Explicitly granted POSIX files/directories, conservative catalog matching, checked private PDF transfer and retry journals. Chat attachments require real client file access.
- Full Library, bookmarks/status/ratings/follows, discussions, notifications and the owner's profile/claims/support. No administrator or reviewer access.
- Real PDF page images, long-page continuation, bounded private cache and note management.
- Exact-body public review creation/editing uses owner browser confirmation. Experimental native chat confirmation stays disabled pending actual client verification.

Fresh-machine email/OAuth, actual attachments and real export samples remain human acceptance tasks. Runtime-free browser reading/import stays available; optional local helpers need Python 3. The package remains rights reserved and has not been submitted to the official directory.

## 0.1.0 · 2026-10-13 · public trial

- Stable plugin identity `prdb`, display name **PRDB**, production reading MCP and shared paper icon.
- Standalone installation/onboarding/feedback guide and pinned public GitHub marketplace.
- Existing OAuth reading, private upload, exact highlights/comments, private review, owner-confirmed publication and selected export workflows use the existing PRDB production service.
- A one-PDF browser import is the runtime-free starting path; the OS picker remains optional.

The plugin version is independent of the website release. Earlier `prdb-reading-preview` installations are not replaced automatically. Fresh-machine human installation/upload testing and generic direct chat attachment transport are separate. This version has not been submitted to the OpenAI public directory.
